# Acme Retail — Storefront

Customer-facing web storefront for Acme Retail, built with React and TypeScript.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Query for data fetching

## Project Structure
- `src/components` — shared UI components
- `src/pages` — route-level views (Home, Product, Checkout)
- `src/api` — client for backend-api service

## Getting Started
```bash
npm install
npm run dev
